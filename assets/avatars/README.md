# Плейсхолдеры - сюда кидай аватарки персонажей

Как добавить аватарку:
1. Закинь файл в assets/avatars/ например anya.png (512x512, круг обрежется сам)
2. Открой scripts/autoload/ChatData.gd
3. В словаре чата добавь поле "avatar": "res://assets/avatars/anya.png"
4. В ChatItem.gd уже есть поддержка - если поле есть, покажет картинку вместо инициалов

Можно также использовать .webp / .jpg для экономии веса (важно для Яндекс.Игр лимит 50мб)
