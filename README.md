# MessengerFax — игра-чаты для Яндекс.Игр (Godot 4.7)

Главное меню в стиле мессенджера: сверху заголовок **«Чаты»**, список персонажей с плейсхолдерами, отдельная вкладка **«Галерея»** для хранения полученных фото.

> Проект настроен под **Godot 4.7 (GL Compatibility)** — экспорт в HTML5 для Яндекс.Игр, VK Игры и других площадок.

---

## 🎮 Как запустить

1. Открой проект в **Godot 4.3+ / 4.7**  
   `project.godot` → главная сцена `res://scenes/Main.tscn` уже назначена.
2. Нажми **▶ Run** (F5).  
   - Портретный режим `432×960` (масштабируется под окно браузера, `canvas_items` + `keep_width`).
   - На десктопе — эмуляция тача включена.

3. Экспорт в веб: **Project → Export → Web (Yandex Games)** → `build/index.html`  
   Готовый пресет уже в `export_presets.cfg`.

## 📱 Что уже готово (Главное меню)

### 1. Экран «Чаты»
- Тёмная тема мессенджера (`#16161A` фон, `#1E1E24` карточки, акцент `#7B61FF`)
- **Header** — `Чаты` + подзаголовок `5 чатов • 2 онлайн` + бейдж непрочитанных + строка поиска
- **Список чатов** (`ChatList`):
  - 5 персонажей-плейсхолдеров: **Аня, Даша, Кира, София, Лера**
  - Каждый чат — `ChatItem`: цветная круглая аватарка с инициалом, имя, время, превью последнего сообщения, бейдж `непрочитанных`, индикатор `онлайн` (зелёная точка), статус `печатает...`
  - Ховер/клик анимация, переход в чат
  - Поиск по имени/сообщению (фильтрация на лету)

### 2. Экран «Галерея»
- Сетка `2 колонки`, карточки с закруглениями
- Пока плейсхолдеры `🔒 заблокировано` — после получения фото станут `🖼️ получено ✓` с фиолетовой рамкой
- Счётчик сверху: `0 / 5 фото получено` + подсказка
- Готова логика разблокировки через `GalleryManager.unlock_photo("chat_01")`

### 3. Экран «Чат» (заглушка диалога)
- Header с аватаркой, именем, статусом `в сети / печатает...`, кнопка Назад `‹`
- Демo-пузырьки сообщений (входящие/исходящие)
- Поле ввода + кнопка отправки (пока тестовый ответ)

### 4. Нижняя навигация
- Две кнопки: `💬 Чаты` и `🖼️ Галерея • 0/5`
- Активная подсвечивается фиолетовым, неактивная — `#2A2A33`
- При входе в чат навигация скрывается, работает `Esc / ui_back`

## 🧩 Как добавить свои данные (плейсхолдеры → реальные)

### Аватарки и никнеймы
1. Закинь картинки в `assets/avatars/` (рекомендую `512×512`, `webp` для веба):
   ```
   assets/avatars/anya.png
   assets/avatars/dasha.webp
   ```
2. Открой `scripts/autoload/ChatData.gd`:
   ```gdscript
   {
       "id": "chat_01",
       "name": "Аня",                # ник
       "initials": "А",              # показывается пока нет картинки
       "avatar": "res://assets/avatars/anya.png", # ← добавь это поле
       "color": Color("#FF6B8A"),
       ...
   }
   ```
   `ChatItem.gd` уже проверяет поле `avatar`: если файл существует — покажет картинку вместо инициала.

### Фото для галереи
1. Закинь в `assets/photos/` (сжимай! для Яндекса важно — `jpg 1080×1920 ~400кб`):
   ```
   assets/photos/anya_01.jpg
   ```
2. В `scripts/autoload/GalleryManager.gd` пропиши путь:
   ```gdscript
   photos["chat_01"] = {
       "character_name": "Аня",
       "unlocked": false,
       "texture_path": "res://assets/photos/anya_01.jpg",
       ...
   }
   ```
3. Разблокировка в чате (когда игрок выполнит условие):
   ```gdscript
   GalleryManager.unlock_photo("chat_01")
   GameManager.save_progress()
   ```

### Логика сохранения
- `GameManager.save_progress()` / `load_progress()` — на вебе пишет в `localStorage`, на десктопе в `user://save.json`.
- Подключи в нужном месте (после получения фото).

## 🎨 Кастом темы
- Цвета лежат прямо в коде как `Color("#7B61FF")` — легко менять палитру.

- Шрифт по умолчанию поддерживает кириллицу (Godot 4 встроенный). Если нужен свой — закинь `*.ttf` в `assets/fonts/` и назначь в Theme.
